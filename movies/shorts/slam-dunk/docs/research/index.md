# 〈두 번째 손〉 조사 색인

감독 열람일은 2026-11-19다. 아래 식별자는 각 조사 본문의 출처와 대본 결정을 연결한다. 이번 납품에는 출처의 위치와 조사자가 한국어로 쓴 적용 기록을 담았다. 원작 지면, 사진, 경기 영상의 복제물은 수록하지 않았다.

| 식별자 | 확인한 원자료와 대목 | 대본에서 쓰인 곳 |
| --- | --- | --- |
| C1 | 공식 영화 사이트의 북산 다섯 선수별 등번호·이름·선수 소개 | 첫 배치, 매치업, 열 명의 식별 |
| C2 | 이노우에 다케히코 《SLAM DUNK》 완전판 22권, 슈에이샤의 권별 소개 | 대만의 외곽슛과 백호의 리바운드 기량 |
| R1 | 이바라키현 고교 보건체육 실기 연수 자료, 규칙 변천과 패스·발동작 | 20분 전후반, 중앙선 통과, 포구와 멈춤 |
| R2 | 야마구치현 농구협회 심판부사 제11·12편, 각 7쪽 | 시대별 코트와 시간 규칙 |
| R3 | 일본농구진흥회 자료 제005호, 다나베 마사미치의 규칙 변천 기록 | 사이드 아웃 때 남은 공격시간, 슛 방출 |
| R4 | 아이즈 농구협회 무로이의 1990년대 규칙 회고 제542호, 1991·1999년 항목 | 작전시간 50초 신호, 득점 뒤 흐르는 시계 |
| R5 | FIBA 중앙이사회 코트 규격 변경 발표, 코트 표식 조항 | 옛 제한구역과 3점선 구별 |
| R6 | FIBA 2008 올림픽 농구 안내와 2008 공식 규칙 2.2.3 | 사다리꼴 오른쪽 빗금을 기준으로 치수의 착지와 7번의 디딤발 구별 |
| P1 | 덴버 너기츠 구단 경기 분석, 마지막 베이스라인 컷 해설 | 센터가 볼 쪽으로 나간 뒤 열리는 길 |
| P2 | NBA의 2013 파이널 6차전 기록, 레이 앨런이 코너로 물러나는 대목 | 패스 전에 발을 준비하는 슈터 |
| B1 | FIBA Venue Guide, 3장 B의 카메라 배치 | 중앙 높은 시야와 엔드라인 낮은 시야 비교 |
