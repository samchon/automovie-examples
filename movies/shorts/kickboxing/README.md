# kickboxing

The story of a kickboxing short, written through the short route: research, then the brief, then the screenplay. This production holds text only. It has no source, Viewer, tests or media, and no film is commissioned.

## Commands

Install once with `pnpm install` at the workspace root, then run here:

| Command | Purpose |
| --- | --- |
| `pnpm run evidence` | The research and narrative evidence obligations of the enabled stages |

## Project files

| Path | Holds |
| --- | --- |
| `PROJECT.md` | The project overview, commissioned scope, current choices and constraints |
| `docs/instructions` | Creative writing requirements |
| `docs/research` | Research studies |
| `docs/body` | The brief and the screenplay |
| Other `docs` locations | Discovery results, evidence answers and reviews |
| `references/` | The retained research originals |
| `evidence.config.ts` | The duties selected through installed `@automovie/evidence`, which `pnpm run evidence` evaluates |

Start with [production](../../../.agents/skills/production/SKILL.md) for the commissioned output and [story](../../../.agents/skills/story/SKILL.md) for the writing. [Document layout](../../../.agents/skills/story/document-layout.md) explains the owners of the `docs` locations.
