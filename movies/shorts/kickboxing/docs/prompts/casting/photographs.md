# Casting photographs

Both fighters, the official, both corners, the timekeeper and the neighbours have separate portraits. The full-length views establish corner colours and clothing at ringside distance. The second view uses that subject’s full-length original as its identity reference. The pairs were selected by the commissioning viewer during the benchmark.

The [generation requests and receipts](requests.json) give the exact prompt, original PNG path, SHA-256 digest, input digest and output identifier for each view. All originals came from OpenAI’s built-in Codex image generator, with opaque backgrounds. The generator supplied the PNG files and output identifiers. Its checkpoint, seed and internal prompt expansions were not exposed.

The production supplied fictional cast descriptions and the full-length originals as inputs. The commissioning account’s OpenAI service terms govern the generated outputs. [OpenAI terms](https://openai.com/policies/terms-of-use/)
