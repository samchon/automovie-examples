R1 was read as a downloaded text extraction with its relevant sections in context. R2's saved XML contains the original authors' abstract and bibliographic record. R3's saved HTML contains the coaching passages. R4 is scanned: all four supplied PDF pages were rendered and opened; pages 3-4 enlarge the same demonstrations on pages 1-2, rather than adding a later moment. Numbered positions establish a qualitative connected path, not a measured kick duration.

The publisher's full text for R2 returned HTTP 403. Its abstract is available and retained, but detailed attack counts and raw footage are unavailable here. An initial PubMed HTML request returned a challenge page; it was discarded after the successful NLM XML retrieval. No finding relies on that failed request. The browser screenshot service also failed on the scanned R4; the downloaded original was instead rendered locally and inspected.

Installed sources read before studying: `@automovie/motions` 0.1.0 README and public declarations for `kick`, `KickRedirect`, `defend`, `knockdown`, `KickboxingRules` and `KnockdownCount`; `@automovie/interface` README and `IAutoMovieCameraAction`. Those already own ordinary single actions and conventional camera moves. They were read in the installed package, not copied into this study. The generic knockdown ends supine, so it is not treated as a supplied right-side fall.
